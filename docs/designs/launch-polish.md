## Implementation Notes (from CEO Review)

### Contrast Strategy
- Body/secondary text: #555 → #999 (5.28:1 ratio, WCAG AA pass)
- Labels/metadata: #444 → #777 (large text or non-essential)

### 404 Routing
- Simple path check in App.jsx — no react-router-dom
- If `window.location.pathname` is not `/` or `/index.html`, render NotFound component

### Scroll-to-Top Positioning
- Fixed bottom-right, above FilmStripProgress
- Hidden when scrollY < viewport height
- GSAP scroll animation on click

### Clipboard Fallback
- Wrap `navigator.clipboard.writeText()` in try/catch
- On failure: show fallback UI (selected text or "copy manually" prompt)
